        Full relative paths; no basename-only matching. Semantics may differ from Git, Docker, Bash, GitHub Actions or other tools.

        Syntax, limits & privacy

        Not supported: negation (!), extglobs, parentheses, character classes/ranges, nested braces, brace ranges, backslash escapes, multiline patterns, or configuration imports. Empty, absolute, control-character, repeated-separator, dot-segment and trailing-slash paths are rejected. A final LF/CRLF is accepted as a line terminator; internal blank lines are errors.

        Limits: 256 characters per pattern; 512 per path; 2,000 provided lines; 3,000 generated candidates; 64 brace combinations; 16 wildcard tokens; 4-second Worker timeout. Limit or timeout results are marked incomplete. Cancel or edit input to discard a running search.

        Analysis runs in your browser. The app does not send inputs, scan files, save inputs to localStorage, call models, or use analytics. Visiting the hosted site still makes normal resource requests and may create hosting logs.
